# Product Positioning

## One-line description

Evergreen Home Control is a local-first smart-home command centre that helps a home stay understandable, repairable, and current as devices and AI tools change.

## Short description

Evergreen Home Control is for people who want smart-home technology without being trapped by one company, one speaker, one app, or one update cycle.

It uses Home Assistant as the practical base, then adds a clearer dashboard, safer status checks, and plain-English summaries on top.

The aim is simple:

```text
Your home should not expire.
```

## What it is

Evergreen Home Control is:

- a local-first control layer
- a clear dashboard for home status
- a rule-based device health checker
- a plain-English summary layer
- an open-source project
- a safer path toward future AI assistance

## What it is not

Evergreen Home Control is not:

- a smart speaker clone
- a new device ecosystem
- a replacement for Home Assistant
- a cloud-first platform
- an AI agent with unchecked power
- a reason to replace working devices

## Who it is for

This project is for people who:

- want their smart home to keep working over time
- prefer local control where possible
- want clear status instead of messy device lists
- want old and new devices to work together
- want AI to explain and help, not take over
- want an open project they can inspect and repair

## Main promise

Evergreen Home Control should make the home easier to understand before it makes the home more automated.

## Public project wording

Use this wording for short descriptions:

```text
A local-first smart-home command centre built on Home Assistant, designed to keep homes understandable, repairable, and current as devices and AI tools change.
```

## Plain-language pitch

Most smart homes depend too much on one company’s hardware, app, cloud service, or assistant.

Evergreen Home Control takes a different route. It keeps Home Assistant as the base, then adds a clearer layer for status, warnings, summaries, and eventually carefully controlled assistance.

The system should help people keep useful devices working instead of pushing them to replace everything.
