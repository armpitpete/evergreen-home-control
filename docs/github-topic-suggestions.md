## Why these fit

| Topic | Why it fits |
|---|---|
| `home-assistant` | Home Assistant is the practical base |
| `smart-home` | The project is a smart-home control layer |
| `local-first` | Local-first design is a core rule |
| `open-source` | The project is intended to be open source |
| `home-automation` | The domain is home automation, even though controls are blocked for now |
| `dashboard` | Current visible work is a dashboard |
| `vite` | The app currently uses Vite |
| `javascript` | The app code is JavaScript |
| `device-health` | Health checking is implemented |
| `privacy-first` | Real homes and private setup details stay out of the public repo |
| `read-only` | Current Home Assistant preparation is read-only |
| `mock-data` | Current dashboard/test flow uses mock and sample data |
