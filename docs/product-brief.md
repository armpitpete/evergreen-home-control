# Product Brief — Evergreen Home Control

## One-line description

A local-first smart-home command centre that keeps devices, automations, AI models, and home status understandable and current.

## Problem

Smart-home products often age badly because the useful parts are tied to one company’s cloud, speaker, app, store, and update cycle.

Old devices are left behind. Assistants become outdated. Users are pushed into buying new hardware instead of keeping a working home system alive.

## Product answer

Evergreen Home Control separates the home brain from the devices and from the AI model.

It uses Home Assistant as the practical base, then adds a clearer control and diagnostics layer above it.

## Target user

A person who wants a smart home that:

- keeps working when brands change
- can use old and new devices together
- avoids cloud lock-in where possible
- explains faults clearly
- can use current AI without depending on one AI provider
- remains repairable

## Core promise

Your home should not expire.

## v0.1 promise

You can open one page and see the important state of the home in plain language.

## Not the product

Evergreen Home Control is not:

- a new smart speaker
- a new bulb ecosystem
- a replacement for Home Assistant
- a cloud-only subscription platform
- a dangerous AI agent with unrestricted device control
